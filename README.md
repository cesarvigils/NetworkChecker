# Full Network Checker Interface

This is a project destined to revise your network status. Right now, these are the functions planned 

- SSID Check (Name, Connected At)
- Full Ping Check (Will Give "Normal Range Values")
- Packet Loss Test (Should calculate packet loss in upstream and downstream channels)
- IP Check (Checks your IP and shows you the approximate Geo-Location, you can use the city as a reference)
- Upload Speed Test
- Download Speed Test 
- Carrier Information, and Carrier Server Information if Possible (would need some more info for that)
- Adding optional "scanner". You could activate the second package, which includes a Downtime Scanner, Disconnection Scanner, and a weekly summary of your actual internet stability.
